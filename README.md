# winterloom

Landing page for winterloom: agentic software for esoteric niches with an asymmetric edge.

- `index.html` is the whole site: plain HTML and CSS, no build step. Serve the repo root as a static site (GitHub Pages: Settings → Pages → deploy from `main`, folder `/`).
- `favicon.svg` is the brand app icon.
- `brand/` holds the identity: `README.md` (guidelines), `tokens.json` / `tokens.css`, outlined logo SVGs in `brand/logos/`, the VT323 font, and `brand/source/gen_logos.py`, which outlines new wordmarks and product lockups (`winterloom/<product>`).

The contact address `hello@winterloom.io` is a placeholder until the real domain is set.
